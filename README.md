# DealFinder — Умный сервис поиска максимальных скидок и честных цен

Современное веб-приложение для поиска самых выгодных товаров, сравнения цен на маркетплейсах (Ozon, Wildberries, Яндекс Маркет, AliExpress, DNS, Temu) и выявления реальной выгоды на основе истории цен.

---

## 🚀 Основные возможности

1. **Алгоритм «Реальная выгода»**:
   - Анализ 90-дневной истории стоимости товара.
   - Защита от искусственно завышенных старых цен продавцов перед распродажами.
   - Наглядные статусы:
     - 🔥 **Очень выгодно** (цена ниже средней на 25%+ и вблизи исторического минимума).
     - 🟢 **Хорошая цена** (честная скидка 12–25%).
     - 🟡 **Обычная цена / Искусственная скидка** (накрученная старая цена, реальная экономия минимальна).
     - 🔴 **Цена выше обычной** (не рекомендуется к покупке).
   - Рейтинг выгодности предложения от 0 до 100 (например, 🔥 95/100, 🔥 82/100, 🟢 68/100).

2. **Интерактивный график цен**:
   - Переключение периодов: **7 дней, 30 дней, 90 дней, 6 месяцев, 1 год**.
   - Отображение текущей цены, минимальной цены за период и средней линии стоимости.

3. **Сравнение цен в магазинах**:
   - Сравнение предложений одного товара на Ozon, Wildberries, Яндекс Маркете, AliExpress, DNS и Temu.
   - Подсветка лучшей цены, условий доставки (срок, бесплатность) и кэшбэка.

4. **Отслеживание цен и алерты**:
   - Настройка уведомлений («Уведомить меня, когда цена станет ниже 900 ₽»).
   - Каналы связи: Telegram (@bot), Email, Web Push.
   - Управление активными алертами в личном кабинете.

5. **Каталог и умные фильтры**:
   - 12 категорий (Электроника, Телефоны, Ноутбуки, Компьютеры, Видеокарты, Игры, Дом, Одежда, Красота, Авто, Спорт, Аксессуары).
   - Фильтрация по цене, размеру скидки, рейтингу, магазину.
   - Чекбоксы: «Только реальные скидки» и «Бесплатная доставка».
   - Сортировка: «Лучшая реальная выгода», «Самая большая скидка», «Самая низкая цена», «Лучший рейтинг», «Новинки».

6. **Избранное, Уведомления и Профиль**:
   - Сохранение в `localStorage` браузера.
   - История динамики цен для избранных товаров.
   - Экран системных уведомлений с реалистичными алертами.
   - Личный кабинет со статистикой сэкономленных средств (34 850 ₽).

---

## 🛠 Технологический стек

- **React 19** + **TypeScript**
- **Vite 8** (мгновенная сборка и HMR)
- **Tailwind CSS v4** (современный адаптивный дизайн)
- **Lucide React** (иконки современного маркетплейса)
- **SVG / Canvas** (интерактивный график истории цен)

---

## 💻 Запуск проекта

### Режим разработки:
```bash
npx vite
```
Сервер запустится на локальном порту:
- **Локально**: `http://localhost:3001`
- **В локальной сети (для смартфона)**: `http://192.168.100.109:3001`

### Сборка для продакшена:
```bash
npm run build
```
Готовые оптимизированные статические файлы находятся в папке `dist/`.
